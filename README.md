# شركة ايراسا — نظام إدارة مصنع الأثاث

برنامج محلي يعمل على حاسوب المالك (ويندوز) لإدارة: المواد الخام والمنتجات التامة، وصفات التصنيع، أوامر الإنتاج، المشتريات والموردين، المبيعات والزبائن، المقبوضات والمدفوعات، الخزينة والمصارف، الموظفين والرواتب والسلف، المصروفات والإيرادات الأخرى، الديون، التذكيرات، التقارير الشهرية، والنسخ الاحتياطي.

- واجهة عربية من اليمين لليسار، والعملة الدينار الليبي (د.ل)، والتوقيت بتوقيت طرابلس.
- لا يحتاج إنترنت أو اشتراكات بعد التثبيت. قاعدة البيانات ملف SQLite على الجهاز نفسه.
- مستخدم واحد فقط هو المالك. الموظفون سجلات بيانات فقط وليس لهم حسابات دخول.

> ⚠️ **تنبيه مهم:** تكلفة المنتج في هذه النسخة = **المواد الخام المستهلكة فعلياً فقط**. العمالة المباشرة والتكاليف غير المباشرة غير محمّلة على المنتج، لذلك «إجمالي الربح التقديري» ليس صافي ربح مدققاً.

---

## 1) المتطلبات

- ويندوز 10 أو 11.
- **Node.js الإصدار 22 LTS** (الحد الأدنى 20.19). حمّله من https://nodejs.org واختر "LTS".
- إنترنت **مرة واحدة فقط** أثناء التثبيت لتنزيل الحزم.

## 2) التثبيت (مرة واحدة)

افتح موجه الأوامر (cmd) أو PowerShell داخل مجلد البرنامج ثم نفّذ:

```bat
npm install
copy .env.example .env
```

افتح ملف `.env` بالمفكرة وغيّر قيمة `SESSION_SECRET` إلى نص عشوائي طويل. يمكنك توليده بالأمر:

```bat
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
```

ثم أنشئ قاعدة البيانات والقوائم الافتراضية وحساب المالك:

```bat
npm run setup
npm run owner:set
npm run build
```

الأمر `owner:set` يطلب اسم المستخدم وكلمة المرور (8 أحرف على الأقل، تحتوي أرقاماً وحروفاً).

## 3) التشغيل اليومي

انقر مرتين على **`start.bat`**. سيطبّق أي ترحيلات لقاعدة البيانات، ثم يشغّل البرنامج ويفتح المتصفح على:

```
http://localhost:3000
```

أو من سطر الأوامر: `npm start`. **لا تغلق النافذة السوداء أثناء الاستخدام**، فإغلاقها يوقف البرنامج. البيانات محفوظة في `data\furniture.db` وتبقى بعد إعادة التشغيل.

يمكنك وضع اختصار لـ `start.bat` على سطح المكتب، أو في مجلد بدء التشغيل (`Win+R` ← `shell:startup`) ليعمل البرنامج تلقائياً مع ويندوز.

## 4) الاستخدام من الهاتف على نفس شبكة Wi-Fi

1. في ملف `.env` غيّر `HOST="127.0.0.1"` إلى `HOST="0.0.0.0"` ثم أعد تشغيل البرنامج.
2. اعرف عنوان IP للحاسوب: نفّذ `ipconfig` وابحث عن `IPv4 Address` (مثل `192.168.1.20`).
3. من الهاتف افتح المتصفح على: `http://192.168.1.20:3000`
4. **جدار حماية ويندوز:** عند أول تشغيل قد تظهر نافذة تطلب السماح لـ Node.js. اختر **الشبكات الخاصة (Private) فقط** ولا تختر العامة. وإن لم تظهر، نفّذ في PowerShell كمسؤول:

```powershell
New-NetFirewallRule -DisplayName "Furniture Manager 3000" -Direction Inbound -Protocol TCP -LocalPort 3000 -Action Allow -Profile Private
```

تأكد أن شبكة Wi-Fi مصنّفة «خاصة» في إعدادات ويندوز (الإعدادات ← الشبكة والإنترنت ← Wi-Fi ← خصائص).

> 🚫 **لا تعرض البرنامج على الإنترنت العام** (لا تفتح المنفذ في الراوتر ولا تستخدم Port Forwarding). البرنامج يرفض تلقائياً أي اتصال من خارج عناوين الشبكة الخاصة (`LOCAL_NETWORK_ONLY="true"`).
> إن احتجت الوصول عن بُعد لاحقاً، استخدم شبكة VPN آمنة مثل **Tailscale** (مجانية للاستخدام الشخصي)، فعناوين Tailscale مسموحة. الوصول عن بُعد ليس شرطاً لعمل البرنامج.

## 5) الأمان وحماية الجهاز

- كلمة المرور مخزّنة مُشفّرة (bcrypt) ولا تُحفظ نصاً أبداً. الجلسة في كعكة httpOnly موقّعة.
- كل صفحة وكل إجراء حفظ يتحقق من جلسة المالك على الخادم.
- قاعدة البيانات (`data\`) والنسخ الاحتياطية (`backups\`) والإيصالات المرفوعة (`storage\`) خارج المجلد العام ولا يمكن تنزيلها من المتصفح إلا عبر مسارات محمية.
- **بياناتك كلها على هذا الحاسوب:** ضع كلمة مرور لحساب ويندوز، وفعّل تشفير القرص (BitLocker) إن أمكن، وانسخ مجلد `backups` دورياً إلى ذاكرة USB أو قرص خارجي يُحفظ في مكان آخر.

### تغيير كلمة المرور / استعادة الدخول

- من داخل البرنامج: **الإعدادات ← كلمة المرور والجلسات**. تغييرها يُخرج كل الأجهزة المسجّلة.
- إن نسيت كلمة المرور: أوقف البرنامج ثم نفّذ `npm run owner:set` من مجلد البرنامج على الحاسوب نفسه. لا يوجد استرجاع عبر الإنترنت لأن البرنامج محلي.

## 6) النسخ الاحتياطي والاستعادة

- **تلقائي:** كل 24 ساعة (قابل للتعديل من الإعدادات) ما دام البرنامج يعمل، ويُحتفظ بآخر 30 نسخة.
- **يدوي:** الإعدادات ← «إنشاء نسخة احتياطية الآن» (يُنصح بها قبل أي عملية كبيرة)، أو الأمر `npm run db:backup`.
- النسخ تُؤخذ بآلية `VACUUM INTO` المدعومة من SQLite، فهي آمنة حتى أثناء الاستخدام، ويُفحص كل ملف (`integrity_check`) بعد إنشائه.

**الاستعادة:**

1. أغلق نافذة البرنامج تماماً.
2. نفّذ (مع اسم الملف من مجلد `backups`):
   ```bat
   npm run db:restore -- furniture-20261017-120000-auto.db
   ```
3. يفحص الأمر سلامة النسخة، ويحفظ القاعدة الحالية باسم `...-pre-restore.db`، ثم يستبدلها، ويفحص القاعدة المستعادة، ويطبّق الترحيلات الناقصة.
4. شغّل البرنامج من جديد.

## 7) التصدير والطباعة

- كل قائمة رئيسية فيها زر **تصدير CSV** (يفتح في Excel بالعربية بشكل صحيح). وكل أنواع التصدير موجودة في صفحة الإعدادات.
- الفاتورة والتقارير: زر **طباعة / حفظ PDF**، ثم اختر «Microsoft Print to PDF» أو «حفظ كـ PDF» في نافذة الطباعة.

## 8) قواعد العمل المهمة

- المخزون لا يُعدّل مباشرة أبداً: كل تغيير حركة مسجّلة (رصيد افتتاحي، شراء، استهلاك إنتاج، إنتاج، بيع، مرتجع، تسوية). الرصيد السالب ممنوع.
- **المسودة** لا تؤثر على المخزون أو الأرقام. **الترحيل** نهائي ولا يتكرر. التصحيح يكون **بالإلغاء** (حركات عكسية مع سبب في سجل التدقيق) أو بالمرتجع.
- إكمال أمر الإنتاج يتم في معاملة واحدة: يخصم المواد ويضيف المنتج ويحسب التكلفة، وإن فشل أي جزء لا يتغير شيء.
- تكلفة المواد تُحسب بطريقة **المتوسط المرجّح**، وتُحفظ لقطة منها في كل فاتورة بيع حتى لا يتغير الربح التاريخي.
- المبيعات ≠ المقبوضات، والمشتريات ≠ المصروفات، والرصيد النقدي ≠ الربح.
- السلفة ليست مصروفاً. مصروف الرواتب = الراتب المستحق + المكافآت − الخصومات، ويُحتسب مرة واحدة.

## 10) حل المشكلات

- **«SESSION_SECRET غير مضبوط»:** تأكد من وجود ملف `.env` وأن القيمة 32 حرفاً على الأقل.
- **صفحة الدخول تقول إن حساب المالك غير موجود:** نفّذ `npm run owner:set`.
- **المنفذ 3000 مستخدم:** غيّر `PORT` في `.env` (مثلاً 3010).
- **الهاتف لا يصل:** تأكد من `HOST="0.0.0.0"`، وأن الهاتف والحاسوب على نفس الشبكة، وأن قاعدة جدار الحماية مفعّلة للشبكة الخاصة.
- **«Unable to open the database file»:** شغّل الأوامر من داخل مجلد البرنامج، وتأكد من وجود المجلد `data`.
- **إيقاف الدخول مؤقتاً:** بعد 5 محاولات خاطئة يُوقف الدخول 15 دقيقة، أو أعد تشغيل البرنامج.
- **فحص سلامة البيانات:** الإعدادات ← «تشغيل الفحص» يطابق كل رصيد مخزني مع مجموع حركاته.

## 11) ما ليس موجوداً في هذه النسخة (مخطط لاحقاً)

- تحميل تكلفة العمالة والتكاليف غير المباشرة على المنتج.
- الإشعارات الخارجية (SMS/واتساب/بريد). التذكيرات حالياً داخل البرنامج فقط وتبقى ظاهرة حتى تُنهى.
- مرتجعات المشتريات للموردين: التصحيح حالياً بإلغاء فاتورة الشراء كاملة (إن لم تُستهلك كمياتها).
- تعديل الفواتير المُرحّلة جزئياً: يتم بالإلغاء وإعادة الإدخال أو بالمرتجع.

## 12) للمطورين

Next.js 15 (App Router) + TypeScript + Tailwind CSS 4 + Prisma 6 + SQLite. المال أعداد صحيحة بالدرهم (1 د.ل = 1000)، والكميات بالألف من الوحدة، بدون أعداد عشرية عائمة. منطق العمل في `src/lib/services`، والاختبارات في `tests/` وتعمل على قواعد بيانات معزولة مُرحّلة بالترحيلات الحقيقية.
